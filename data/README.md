# Sample Data

These CSV files are minimal synthetic datasets for testing and demonstrating the FigureSpec protocol.

| File | Used in | Plot Type |
|------|---------|-----------|
| `panel_a_line_trends.csv` | any_figure_demo, 2x2 demo | Line with uncertainty band |
| `panel_b_grouped_bar_wide.csv` | 2x2 demo | Grouped bar |
| `panel_c_scatter_correlation.csv` | 2x2 demo | Scatter with size encoding |
| `panel_d_heatmap_matrix.csv` | 2x2 demo | Matrix heatmap |

Replace these with your real experimental data when using the skill.
